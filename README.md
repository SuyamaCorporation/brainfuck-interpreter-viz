## Brainf*ckインタープリタ（ビジュアル）

難解プログラミング言語Brainfuckのプログラムをステップ実行し、メモリセル・命令ポインタ・データポインタをリアルタイムアニメーションで可視化するインタープリタ。

### 機能
- 完全なBrainfuck実行エンジン（30000セル対応）
- 命令ポインタ・データポインタのリアルタイム可視化
- メモリセル30セルをカラーアニメーション表示
- サンプルプログラム5種（Hello World、フィボナッチ、加算、文字列逆順、catプログラム）
- ステップ実行・連続実行・一時停止・リセット
- 実行速度5段階調整（最遅〜最速）
- 最大ステップ数の上限設定（無限ループ防止）
- 命令セットリファレンス表示

### 技術
- 静的SPA（index.html単体）
- Tailwind CSS CDN
- Uint8Array（30000セルメモリ）
- setTimeout による非同期ステップ実行アニメーション
